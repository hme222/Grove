# Pip's Nook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Pip's nook: an optional pixel nook that fills in as a new user learns and cares, with Pip as the guide, a readiness plant for people with no plant yet, and a daily note on Care Today.

**Architecture:** The backend adds two modules. `nook.py` holds the rules as pure functions (growth from existing signals, levels, plant condition, weekly rhythm). `nook_service.py` reads Grove's existing data and builds the nook state, and `server.py` exposes it through a few endpoints. The frontend adds a `nook/` folder: whole-number pixel sprites, a canvas room drawn from one view object, and small components. Nothing the nook shows is a number.

**Tech Stack:** FastAPI + Motor + pytest (backend). React 19, craco (CRA jest), canvas 2D, Storybook 8 (frontend).

**Spec:** `docs/superpowers/specs/2026-10-13-pip-room-design.md` (v5.2 plus the corrections after it). **Depends on:** Plan 1 (`docs/superpowers/plans/2026-10-14-lessons-quiz-soil-test.md`), which is on branch `feat/lessons-quiz-soil-test`. Start from that branch, or from `storybook` once its pull request is merged. This plan uses Plan 1's `tracks.py`, the `soil_check` care action, the lesson pages, and the quiz.

## Decisions made while planning

The spec is the authority. Where this plan differs from it, the difference is here, with what it costs if wrong.

1. **The offer fires after a first care log or a first finished lesson, whichever comes first.** The spec says "first care log, or for a user with no plant, the first readiness step." The readiness plant lives inside the nook, which is opt-in, so a no-plant user could never reach it before the offer. A finished lesson is their first real action instead. Cost if wrong: the offer reaches no-plant users a lesson earlier or later than intended.
2. **Sprites are 15 pixels wide and up to 24 tall, not 16 by 16.** An odd width gives every sprite a centre column, and the bloom form with its pot cannot fit in 16 rows. The nook is still 128 by 80. Cost if wrong: re-draw the sprite maps.
3. **Pip's note shows today's trivia card.** Grove's trivia deck already includes a "Care tip" category, so the note alternates trivia and tips without a new tips list. Cost if wrong: a separate tips list is added later.
4. **Level badges are awarded when a user who opted in reaches the level, and are hidden from the gallery until then.** They are not pinned as "working toward" goals, because that screen shows progress as numbers and the spec says the interface shows none. Cost if wrong: add a progress rule in `badge_progress.py` and accept numbers on that screen.
5. **The choose-your-own decor catalog is not built here.** The state only reports `catalog_open`. Catalog art and choosing belong with Plan 3. Cost if wrong: a later plan carries the extra work.
6. **The shelf draws at most two small plants.** It is 46 pixels wide and Pip needs room. The state and the page still list up to four. Cost if wrong: widen the shelf or draw smaller pots.
7. **Pip hosts a lesson from a panel above the card, not inside it.** It keeps the lesson card's own look untouched. Cost if wrong: move the panel into the card.
8. **Plant condition is worked out for at most 30 plants, with one health query each.** Cost if wrong: add paging or caching.
9. **The art is a first pass.** It was checked by eye as images, and a designer should polish it in Storybook. Cost if wrong: swap the sprite maps; nothing else depends on them.

## Global Constraints

- The nook is opt-in. It is offered once, after a new user's first real action, with a short Pip preview. Either answer is saved and the offer is never repeated.
- No core Grove feature requires the nook. Without it, lessons, missions, badges, trivia, and Care Today work as they do now.
- The interface shows no numbers for growth. It only says that the nook grew.
- Growth values: lesson +15, soil test +15, light check +10, leaves wiped +5, readiness step +10, badge +20, mission = its own XP. A soil test counts once per plant per day. A light check or leaf wipe counts once per plant per 14 days. Lessons, readiness steps, missions, and badges count once each. No more than 30 growth counts on any one day.
- Levels: 1 Bare (0), 2 Settling in (100), 3 Lived in (200), 4 In bloom (300). Unlocks are never removed.
- Pip is the guide, not a plant. Pip never droops and never reflects plant health. His mood is cosmetic and follows the time of day.
- Pip starts on the windowsill and moves to the shelf at level 2. He grows through four forms: seed, sprout, leafy, and bloom.
- Real plants never get faces and never bloom on screen. Each plant sprite shows one of three conditions: fine, due-soon, needs-attention, from the plant's schedule, the user's "looks off" flag, and Grove's health check, never from nook growth.
- The readiness plant has only seed, sprouting, and ready states. It has no needs and no care actions. At ready it shows the species' real watering schedule and offers to add a real plant.
- While any real plant needs attention, Pip is quiet and supportive and does not celebrate.
- The nook is 128 by 80 pixels and is scaled by whole numbers only, never below 2x, except the small Care Today picture at 1x. Motion stops when the user prefers reduced motion.
- The canvas is a picture. The same state must also be written as text on the page.
- A real plant sprite always says what it is based on: "From your records and Grove's plant check".
- Nothing a user earned is ever removed. No guilt copy. Copy is warm and plain.
- Level badges: `nook_level_2`, `nook_level_3`, `nook_level_4`. They are only awarded to users who opted in.
- Backend tests are pytest. Frontend tests run through `npm test` (craco, jest). Jest here cannot resolve the `@/` alias or load `react-router-dom` v7, so tests mock those, as Plan 1's tests do.

## Review Focus

Failure modes the spec implies but a straight reading would not test. Each is covered by a test in the task that owns the code.

1. **A plant needs attention on the same day the nook levels up.** Expected: Pip does not celebrate, and the page says nothing cheerful. (Task 6 `pipLine`, Task 10 `NookPage`.)
2. **A lesson finished before times were recorded, or a user with no signals at all.** Expected: no crash, and the lesson counts once without a day. (Task 1, Task 2.)
3. **More plants than the shelf holds, an archived plant, or a hero plant that was deleted.** Expected: the hero falls back to the oldest plant, the shelf is capped, and nothing breaks. (Task 2, Task 5.)
4. **Opting out and in again, or a double tap on any button.** Expected: the offer is recorded once, level badges only come after opt-in, and a tap never saves twice. (Task 2, Task 3, Task 8, Task 10, Task 11.)
5. **Reduced motion, or a browser with no canvas.** Expected: nothing moves, nothing throws, and the written state still says everything. (Task 7, Task 10.)

```python
"""Pip's nook: the rules that turn Grove's existing signals into nook state.

Pure functions only, with no database access, so they can be unit tested.
Growth is always derived from the event log. It is never a stored counter.
The interface never shows these numbers; it only says the nook grew.
"""
from datetime import datetime, timedelta, timezone
from typing import Dict, Iterable, List, Optional

DAILY_CAP = 30
ROLLING_DAYS = 14
LOW_HEALTH_SCORE = 30
CATALOG_DAYS = 30

# (level, name, growth needed)
LEVELS = (
    (1, "Bare", 0),
    (2, "Settling in", 100),
    (3, "Lived in", 200),
    (4, "In bloom", 300),
)

# What each level adds to the nook.
UNLOCKS = {
    1: ["window", "table", "sill", "floor"],
    2: ["shelf"],
    3: ["rug", "lamp"],
    4: ["hanging", "wall-art"],
}

# Shown as "Next: ..." so the interface can name the next unlock without numbers.
NEXT_UNLOCK_TEXT = {
    2: "the shelf",
    3: "a rug and a lamp",
    4: "a hanging plant and a botanical print",
}

# Growth per signal. Missions bring their own XP.
POINTS = {
    "lesson": 15,
    "soil_check": 15,
    "light_check": 10,
    "leaves_wiped": 5,
    "readiness_step": 10,
    "badge": 20,
}

READINESS_STEPS = ("light-spot", "drainage", "soil-mix")
NOOK_BADGE_PREFIX = "nook_level_"

PIP_FORMS = {1: "seed", 2: "sprout", 3: "leafy", 4: "bloom"}

SPECIES_GROUPS = (
    ("pothos", ("pothos", "epipremnum")),
    ("monstera", ("monstera",)),
    ("succulent", ("succulent", "echeveria", "aloe", "jade", "crassula", "haworthia", "sedum")),
    ("snake", ("snake plant", "sansevieria", "trifasciata")),
)


def _parse(value) -> Optional[datetime]:
    """Parse an ISO timestamp to an aware UTC datetime. Anything unreadable is None."""
    if not value or not isinstance(value, str):
        return None
    try:
        parsed = datetime.fromisoformat(value.replace("Z", "+00:00"))
    except ValueError:
        return None
    if parsed.tzinfo is None:
        parsed = parsed.replace(tzinfo=timezone.utc)
    return parsed.astimezone(timezone.utc)


def compute_growth(events: Iterable[dict]) -> int:
    """Total nook growth from a list of events.

    Each event is a dict with `kind`, optional `at` (ISO time), `key`,
    `plant_id`, and `points`. Limits:
      - lessons, readiness steps, missions, and badges count once each;
      - a soil test counts once per plant per day;
      - a light check or leaf wipe counts once per plant per 14 days;
      - no more than 30 growth counts on any one day.
    Events with no readable time ("undated") count once, outside the daily cap.
    Nook level badges never count, so levels cannot feed themselves.
    """
    dated = []
    undated = []
    for event in events or []:
        when = _parse(event.get("at"))
        (dated if when else undated).append((when, event))
    dated.sort(key=lambda pair: pair[0])

    seen_once = set()
    soil_days = set()
    last_counted: Dict[tuple, Optional[datetime]] = {}

    def points_for(event: dict) -> int:
        if event.get("points") is not None:
            return max(0, int(event["points"]))
        return POINTS.get(event.get("kind"), 0)

    def accept(event: dict, when: Optional[datetime]) -> bool:
        kind = event.get("kind")
        if kind == "badge" and str(event.get("key") or "").startswith(NOOK_BADGE_PREFIX):
            return False
        if kind in ("lesson", "readiness_step", "badge", "mission"):
            marker = (kind, event.get("key"))
            if marker in seen_once:
                return False
            seen_once.add(marker)
            return True
        if kind == "soil_check":
            marker = (event.get("plant_id"), when.date() if when else None)
            if marker in soil_days:
                return False
            soil_days.add(marker)
            return True
        if kind in ("light_check", "leaves_wiped"):
            marker = (kind, event.get("plant_id"))
            last = last_counted.get(marker)
            if last is not None and when is not None and when - last < timedelta(days=ROLLING_DAYS):
                return False
            last_counted[marker] = when
            return True
        return False

    per_day: Dict = {}
    for when, event in dated:
        if not accept(event, when):
            continue
        day = when.date()
        room = DAILY_CAP - per_day.get(day, 0)
        per_day[day] = per_day.get(day, 0) + max(0, min(points_for(event), room))

    total = sum(per_day.values())
    for when, event in undated:
        if accept(event, None):
            total += points_for(event)
    return total

    """The sprite state for a real plant: fine, due-soon, or needs-attention.

    It comes from the plant's schedule status, the user's "looks off" flag, and
    Grove's health check. It never comes from nook growth.
    """
    if looks_off or status == "urgent":
        return "needs-attention"
    if any(score < LOW_HEALTH_SCORE for score in (health_scores or [])):
        return "needs-attention"
    if status == "needs_water":
        return "due-soon"
    return "fine"

def weekly_days(timestamps: Iterable[str], now: datetime) -> int:
    """How many different days this week (Monday to Sunday, UTC) the user showed up."""
    today = now.astimezone(timezone.utc).date()
    start = today - timedelta(days=today.weekday())
    end = start + timedelta(days=6)
    days = set()
    for stamp in timestamps or []:
        when = _parse(stamp)
        if when and start <= when.date() <= end:
            days.add(when.date())
    return len(days)

    """The choose-your-own decor catalog opens 30 days after signup, for users with the nook on."""
    created = _parse(created_at)
    if not enabled or created is None:
        return False
    return now - created >= timedelta(days=CATALOG_DAYS)

    """The readiness plant's only states: seed, sprouting, and ready. It never has a need."""
    if steps_done <= 0:
        return "seed"
    if steps_done >= len(READINESS_STEPS):

    return "sprouting"

        if not str(badge.get("slug") or "").startswith(NOOK_BADGE_PREFIX) or badge.get("slug") in earned
    ]
```

```python
"""A small in-memory stand-in for the database, shared by the nook tests.

It supports exactly what the nook code uses: equality filters, `$ne`, `$in`,
`find().sort().limit().to_list()`, and `$set` / `$addToSet` updates, including
dotted keys such as `readiness_plant.steps.drainage`.
"""


def matches(doc, flt):
    for key, value in flt.items():
        if isinstance(value, dict):
            if "$ne" in value and doc.get(key) == value["$ne"]:
                return False
            if "$in" in value and doc.get(key) not in value["$in"]:
                return False
        elif doc.get(key) != value:
            return False
    return True


class Cursor:
    def __init__(self, docs):
        self.docs = list(docs)

    def sort(self, key, direction=1):
        self.docs.sort(key=lambda d: d.get(key) or "", reverse=direction < 0)
        return self

    def limit(self, n):
        self.docs = self.docs[:n]
        return self

    async def to_list(self, n=None):
        return self.docs if n is None else self.docs[:n]


def _set_path(doc, path, value):
    parts = path.split(".")
    for part in parts[:-1]:
        doc = doc.setdefault(part, {})
    doc[parts[-1]] = value


class Collection:
    def __init__(self):
        self.docs = []

    async def insert_one(self, doc):
        self.docs.append(doc)

    async def find_one(self, flt, projection=None):
        for doc in self.docs:
            if matches(doc, flt):
                return doc
        return None

    def find(self, flt=None, projection=None):
        return Cursor(d for d in self.docs if matches(d, flt or {}))

    async def count_documents(self, flt):
        return sum(1 for d in self.docs if matches(d, flt))

    async def update_one(self, flt, update):
        doc = await self.find_one(flt)
        if doc is None:
            return
        for key, value in update.get("$set", {}).items():
            _set_path(doc, key, value)
        for key, value in update.get("$addToSet", {}).items():
            items = doc.setdefault(key, [])
            if value not in items:
                items.append(value)


class FakeDb:
    def __init__(self):
        for name in ("users", "plants", "care_logs", "user_missions", "user_badges", "badges", "species"):
            setattr(self, name, Collection())
```

```python
        super().__init__(detail)
        self.status = status
        self.detail = detail


async def gather_events(db, user_id: str, user: dict) -> List[dict]:
    """Every signal that can grow the nook, as plain event dicts."""
    events: List[dict] = []

    stamps = user.get("lesson_completed_at") or {}
    for lesson_id in tracks.completed_lessons(user.get("tutorials_seen")):
        events.append({"kind": "lesson", "key": lesson_id, "at": stamps.get(lesson_id)})

    logs = await db.care_logs.find({"user_id": user_id, "action": {"$in": list(CARE_KINDS)}}).to_list(5000)
    for log in logs:
        events.append({"kind": CARE_KINDS[log["action"]], "plant_id": log.get("plant_id"), "at": log.get("logged_at")})

    for step_id, when in ((user.get("readiness_plant") or {}).get("steps") or {}).items():
        events.append({"kind": "readiness_step", "key": step_id, "at": when})

    missions = await db.user_missions.find({"user_id": user_id, "completed_at": {"$ne": None}}).to_list(1000)
    for mission in missions:
        events.append({
            "kind": "mission",
            "key": mission.get("id"),
            "at": mission.get("completed_at"),
            "points": mission.get("xp_awarded") or 0,
        })

    for earned in await db.user_badges.find({"user_id": user_id}).to_list(500):
        events.append({"kind": "badge", "key": earned.get("badge_slug"), "at": earned.get("earned_at")})
    return events


async def activity_stamps(db, user_id: str, user: dict) -> List[str]:
    """Every time the user showed up: any care log, a lesson, or a readiness step."""
    stamps = [log.get("logged_at") for log in await db.care_logs.find({"user_id": user_id}).to_list(5000)]
    stamps.extend((user.get("lesson_completed_at") or {}).values())
    stamps.extend(((user.get("readiness_plant") or {}).get("steps") or {}).values())
    return stamps


async def current_growth(db, user_id: str) -> int:
    user = await db.users.find_one({"id": user_id}) or {}
    return nook.compute_growth(await gather_events(db, user_id, user))


async def build_state(
    db,
    user_id: str,
    now: datetime,
    status_fn: Callable[[dict], str],
    scores_fn: Callable[[dict], Awaitable[List[int]]],
) -> dict:
    """Everything the nook screen needs. It never includes the growth number."""
    user = await db.users.find_one({"id": user_id}) or {}
    growth = nook.compute_growth(await gather_events(db, user_id, user))
    info = nook.level_info(growth)
    level = info["level"]

    plants = await db.plants.find({"user_id": user_id, "is_archived": {"$ne": True}}).to_list(200)
    plants.sort(key=lambda plant: plant.get("created_at") or "")
    rows: List[Dict] = []
    for plant in plants[:MAX_PLANTS]:
        condition = nook.plant_condition(status_fn(plant), bool(plant.get("looks_off")), await scores_fn(plant))
        rows.append({
            "id": plant["id"],
            "name": plant.get("nickname") or plant.get("common_name") or "Plant",
            "group": nook.species_group(plant.get("common_name"), plant.get("latin_name")),
            "condition": condition,
            "looks_off": bool(plant.get("looks_off")),
        })

    chosen = user.get("nook_hero_plant_id")
    hero = next((row for row in rows if row["id"] == chosen), None) or (rows[0] if rows else None)
    shelf = [row for row in rows if hero and row["id"] != hero["id"]][:MAX_SHELF_PLANTS]

    readiness = None
    started = user.get("readiness_plant")
    if started:
        done = started.get("steps") or {}
        count = sum(1 for step in nook.READINESS_STEPS if step in done)
        readiness = {
            "species_id": started.get("species_id"),
            "species_name": started.get("species_name"),
            "watering_days": started.get("watering_days") or 7,
            "group": nook.species_group(started.get("species_name")),
            "steps": [{"id": step, "done": step in done} for step in nook.READINESS_STEPS],
            "state": nook.readiness_state(count),
        }

    enabled = bool(user.get("nook_enabled"))
    return {
        "enabled": enabled,
        "offered": bool(user.get("nook_offered_at")),
        "level": level,
        "level_name": info["name"],
        "next_unlock": info["next_unlock"],
        "unlocked": nook.unlocked_slots(level),
        "grew": growth > (user.get("nook_seen_growth") or 0),
        "level_up": level > (user.get("nook_seen_level") or 1),
        "pip": {"form": nook.pip_form(level), "location": nook.pip_location(level)},
        "hero": hero,
        "shelf_plants": shelf,
        "plants": rows,
        "readiness": readiness,
        "quiet": nook.is_quiet(row["condition"] for row in rows),
        "weekly_days": nook.weekly_days(await activity_stamps(db, user_id, user), now),
        "catalog_open": nook.catalog_open(user.get("created_at"), now, enabled),
    }


async def award_level_badges(db, user_id: str, level: int, now_iso: str) -> List[str]:
    """Give the level badges the user has reached. Safe to call again."""
    awarded: List[str] = []
    for number in range(2, level + 1):
        slug = f"{nook.NOOK_BADGE_PREFIX}{number}"
        if await db.user_badges.find_one({"user_id": user_id, "badge_slug": slug}):
            continue
        badge = await db.badges.find_one({"slug": slug})
        if not badge:
            continue
        await db.user_badges.insert_one({
            "id": str(uuid.uuid4()),
            "user_id": user_id,
            "badge_id": badge["id"],
            "badge_slug": slug,
            "earned_at": now_iso,
        })
        awarded.append(slug)
    return awarded


async def mark_seen(db, user_id: str, now_iso: str) -> None:
    """Remember what the user has seen, so "your nook grew" shows once."""
    user = await db.users.find_one({"id": user_id}) or {}
    growth = nook.compute_growth(await gather_events(db, user_id, user))
    await db.users.update_one(
        {"id": user_id},
        {"$set": {
            "nook_seen_growth": growth,
            "nook_seen_level": nook.level_info(growth)["level"],
            "updated_at": now_iso,
        }},
    )


async def update_settings(db, user_id: str, enabled, hero_plant_id, now_iso: str) -> dict:
    """Turn the nook on or off and choose the hero plant. Returns the saved fields."""
    user = await db.users.find_one({"id": user_id}) or {}
    updates: Dict = {}
    if hero_plant_id is not None:
        if not await db.plants.find_one({"id": hero_plant_id, "user_id": user_id}):
            raise NookError(404, "Plant not found")
        updates["nook_hero_plant_id"] = hero_plant_id
    if enabled is not None:
        updates["nook_enabled"] = bool(enabled)
        # The offer is recorded once, so it is never made again.
        if not user.get("nook_offered_at"):
            updates["nook_offered_at"] = now_iso
    if updates:
        updates["updated_at"] = now_iso
        await db.users.update_one({"id": user_id}, {"$set": updates})
    saved = await db.users.find_one({"id": user_id}) or {}
    return {
        "nook_enabled": bool(saved.get("nook_enabled")),
        "nook_offered_at": saved.get("nook_offered_at"),
        "nook_hero_plant_id": saved.get("nook_hero_plant_id"),
    }


async def start_readiness(db, user_id: str, species_id: str, now_iso: str) -> None:
    """Pick the species the user is getting ready for. Steps already done are kept."""
    species = await db.species.find_one({"id": species_id})
    if not species:
        raise NookError(404, "Species not found")
    user = await db.users.find_one({"id": user_id}) or {}
    existing = user.get("readiness_plant") or {}
    await db.users.update_one(
        {"id": user_id},
        {"$set": {
            "readiness_plant": {
                "species_id": species_id,
                "species_name": species.get("common_name"),
                "watering_days": species.get("default_watering_days") or 7,
                "started_at": existing.get("started_at") or now_iso,
                "steps": existing.get("steps") or {},
            },
            "updated_at": now_iso,
        }},
    )


async def complete_readiness_step(db, user_id: str, step_id: str, now_iso: str) -> None:
    """Mark a readiness step done. Safe to call twice."""
    if step_id not in nook.READINESS_STEPS:
        raise NookError(404, "Step not found")
    user = await db.users.find_one({"id": user_id}) or {}
    started = user.get("readiness_plant")
    if not started:
        raise NookError(409, "Pick a plant to get ready for first.")
    if step_id in (started.get("steps") or {}):
        return
    await db.users.update_one(
        {"id": user_id},
        {"$set": {f"readiness_plant.steps.{step_id}": now_iso, "updated_at": now_iso}},
    )


async def set_looks_off(db, user_id: str, plant_id: str, looks_off: bool, now_iso: str) -> None:
    """Flag a plant as looking off, or clear the flag."""
    if not await db.plants.find_one({"id": plant_id, "user_id": user_id}):
        raise NookError(404, "Plant not found")
    await db.plants.update_one(
        {"id": plant_id},
        {"$set": {"looks_off": bool(looks_off), "updated_at": now_iso}},
    )
```

```javascript
const LEAF_LETTERS = 'gGd';
const MUTED = { g: 'm', G: 'n', d: 'n' };

// Side leaves sag one pixel; the centre column (the stem) stays put.
function droop(rows) {
  const grid = rows.map((row) => row.split(''));
  for (let y = grid.length - 2; y >= 0; y -= 1) {
    for (let x = 0; x < SPRITE_WIDTH; x += 1) {
      if (x !== CENTER && LEAF_LETTERS.includes(grid[y][x]) && grid[y + 1][x] === '.') {
        grid[y + 1][x] = grid[y][x];
        grid[y][x] = '.';
      }
    }
  }
  return grid.map((row) => row.join(''));
}

// A plant's condition changes its shape and colour, and the page always adds a text label.
export function applyCondition(rows, condition) {
  if (condition === 'due-soon') {
    const grid = rows.map((row) => row.split(''));
    if (grid.length > 1 && grid[0][12] === '.' && grid[1][12] === '.') {
      grid[0][12] = 'b';
      grid[1][12] = 'b';
    }
    return grid.map((row) => row.join(''));
  }
  if (condition === 'needs-attention') {
    return droop(rows).map((row) => row.replace(/[gGd]/g, (c) => MUTED[c]));
  }
  return rows.slice();
}

export function pipSprite(form, mood = 'calm') {
  const top = PIP_TOPS[form] || PIP_TOPS.seed;
  const pot = FACE_POTS[mood] || FACE_POTS.calm;
  return [...top, ...pot];
}

  const top = PLANT_TOPS[group] || PLANT_TOPS.generic;
  return [...applyCondition(top, condition), ...PLAIN_POT];
}

export function seedlingSprite(stage) {
  const top = SEEDLING_TOPS[stage] || SEEDLING_TOPS.seed;
  return [...top, ...PLAIN_POT];
```

```javascript
import { PALETTE, ROOM } from './palette';
import { pipSprite, plantSprite, seedlingSprite, CENTER } from './sprites';

// The nook is a fixed 128 x 80 pixel scene. Every position below is in those
// logical pixels. The canvas is scaled up by whole numbers only.
export const ROOM_W = 128;
export const ROOM_H = 80;

// Where Pip stands. He starts on the windowsill and moves to the shelf at level 2.
export const PIP_SPOTS = {
  sill: { cx: 29, baseY: 37 },
  shelf: { cx: 82, baseY: 25 },
};
export const HERO_SPOT = { cx: 65, baseY: 49 };

const rect = (ctx, x, y, w, h, color) => {
  ctx.fillStyle = color;
  ctx.fillRect(x, y, w, h);
};

// A faint outline that shows where something will appear once it unlocks.
function ghost(ctx, x, y, w, h) {
  ctx.fillStyle = ROOM.ghost;
  ctx.fillRect(x, y, w, 1);
  ctx.fillRect(x, y + h - 1, w, 1);
  ctx.fillRect(x, y, 1, h);
  ctx.fillRect(x + w - 1, y, 1, h);
}

// Draws a sprite so its bottom row sits on `baseY` and its centre column on `cx`.
export function drawSprite(ctx, rows, cx, baseY) {
  const top = baseY - rows.length + 1;
  const left = cx - CENTER;
  rows.forEach((row, y) => {
    for (let x = 0; x < row.length; x += 1) {
      const color = PALETTE[row[x]];
      if (color) rect(ctx, left + x, top + y, 1, 1, color);
    }
  });
}

function drawBackdrop(ctx) {
  rect(ctx, 0, 0, ROOM_W, 56, ROOM.wall);
  rect(ctx, 0, 40, ROOM_W, 14, ROOM.wainscot);
  rect(ctx, 0, 40, ROOM_W, 1, ROOM.wainscotLine);
  rect(ctx, 0, 54, ROOM_W, 2, ROOM.baseboard);
  rect(ctx, 0, 56, ROOM_W, 24, ROOM.floor);
  [60, 65, 71, 77].forEach((y) => rect(ctx, 0, y, ROOM_W, 1, ROOM.plank));
  [20, 52, 90, 110].forEach((x, i) => rect(ctx, x, 56 + i * 5, 1, 5, ROOM.plank));
  // window, sill, and the light it throws on the floor
  rect(ctx, 14, 8, 30, 30, ROOM.windowFrame);
  [[16, 10], [30, 10], [16, 24], [30, 24]].forEach(([x, y]) => rect(ctx, x, y, 12, 12, ROOM.sky));
  rect(ctx, 12, 38, 34, 2, ROOM.sill);
  for (let y = 56; y < 80; y += 1) rect(ctx, Math.round(22 + (y - 56) * 0.9), y, 28, 1, ROOM.beam);
}

function drawTable(ctx) {
  rect(ctx, 52, 50, 26, 3, ROOM.wood);
  rect(ctx, 52, 50, 26, 1, ROOM.woodLight);
  rect(ctx, 54, 53, 2, 13, ROOM.woodDark);
  rect(ctx, 74, 53, 2, 13, ROOM.woodDark);
}

// A small potted plant for the shelf: a pot and a leaf blob in the plant's condition colour.
function drawMiniPlant(ctx, x, baseY, condition) {
  const leaf = condition === 'needs-attention' ? PALETTE.n : PALETTE.G;
  rect(ctx, x + 1, baseY - 6, 3, 3, leaf);
  if (condition === 'due-soon') rect(ctx, x + 4, baseY - 8, 1, 2, PALETTE.b);
  rect(ctx, x, baseY - 3, 5, 3, PALETTE.t);
  rect(ctx, x, baseY - 3, 5, 1, PALETTE.u);
}

function drawShelf(ctx, unlocked, shelfPlants) {
  if (!unlocked.includes('shelf')) {
    ghost(ctx, 72, 14, 46, 14);
    return;
  }
  rect(ctx, 72, 26, 46, 2, ROOM.wood);
  rect(ctx, 76, 28, 1, 3, ROOM.woodDark);
  rect(ctx, 112, 28, 1, 3, ROOM.woodDark);
  rect(ctx, 92, 18, 3, 8, PALETTE.t);
  rect(ctx, 95, 16, 3, 10, PALETTE.G);
  rect(ctx, 98, 19, 3, 7, PALETTE.p);
  rect(ctx, 101, 17, 3, 9, PALETTE.d);
  shelfPlants.slice(0, 2).forEach((plant, i) => drawMiniPlant(ctx, 106 + i * 6, 26, plant.condition));
}

function drawRugAndLamp(ctx, unlocked) {
  if (unlocked.includes('rug')) {
    rect(ctx, 38, 66, 52, 10, ROOM.rug);
    rect(ctx, 36, 68, 56, 6, ROOM.rug);
    rect(ctx, 41, 68, 46, 6, ROOM.rugInner);
    rect(ctx, 44, 70, 40, 2, ROOM.rugStripe);
  } else {
    ghost(ctx, 36, 66, 56, 10);
  }
  if (unlocked.includes('lamp')) {
    rect(ctx, 6, 36, 1, 30, ROOM.lampPole);
    rect(ctx, 2, 30, 9, 6, ROOM.lampShade);
    rect(ctx, 3, 29, 7, 1, ROOM.lampTop);
    rect(ctx, 3, 64, 7, 2, ROOM.lampPole);
  } else {
    ghost(ctx, 2, 30, 9, 36);
  }
}

const VINES = [
  [120, 13], [121, 15], [120, 17], [122, 19], [121, 22], [123, 24], [125, 15],
  [126, 18], [125, 21], [126, 26], [124, 29], [122, 31], [120, 27],
];

function drawHangingAndArt(ctx, unlocked) {
  if (unlocked.includes('hanging')) {
    rect(ctx, 123, 0, 1, 8, ROOM.cord);
    rect(ctx, 119, 8, 9, 5, PALETTE.t);
    VINES.forEach(([x, y]) => rect(ctx, x, y, 2, 2, PALETTE.G));
    rect(ctx, 124, 17, 1, 1, PALETTE.g);
    rect(ctx, 121, 25, 1, 1, PALETTE.g);
  } else {
    ghost(ctx, 119, 0, 9, 34);
  }
  if (unlocked.includes('wall-art')) {
    rect(ctx, 54, 8, 18, 18, ROOM.wood);
    rect(ctx, 56, 10, 14, 14, ROOM.rugInner);
    rect(ctx, 62, 13, 2, 9, PALETTE.G);
    rect(ctx, 59, 15, 3, 2, PALETTE.g);
    rect(ctx, 64, 17, 3, 2, PALETTE.g);
  } else {
    ghost(ctx, 54, 8, 18, 18);
  }
}

function drawHero(ctx, view) {
  const { cx, baseY } = HERO_SPOT;
  if (view.hero) {
    drawSprite(ctx, plantSprite(view.hero.group, view.hero.condition), cx, baseY);
  } else if (view.readiness) {
    const rows = view.readiness.state === 'ready'
      ? plantSprite(view.readiness.group, 'fine')
      : seedlingSprite(view.readiness.state);
    drawSprite(ctx, rows, cx, baseY);
  } else {
    ghost(ctx, cx - 6, baseY - 8, 13, 9);
  }
}

// Draws the whole nook for one view. `tick` flips Pip's small bob; pass 0 for a still image.
//   view = { unlocked: string[], pip: { form, location, mood },
//            hero: { group, condition } | null,
//            readiness: { state, group } | null,
//            shelfPlants: { condition }[] }
export function drawRoom(ctx, view, tick = 0) {
  const unlocked = view.unlocked || [];
  drawBackdrop(ctx);
  drawRugAndLamp(ctx, unlocked);
  drawHangingAndArt(ctx, unlocked);
  drawShelf(ctx, unlocked, view.shelfPlants || []);
  drawTable(ctx);
  drawHero(ctx, view);
  const spot = PIP_SPOTS[view.pip.location] || PIP_SPOTS.sill;
  const bob = tick % 2 ? -1 : 0;
  drawSprite(ctx, pipSprite(view.pip.form, view.pip.mood), spot.cx, spot.baseY + bob);
}
```

```jsx
import React, { useEffect, useLayoutEffect, useRef, useState } from 'react';
import { drawRoom, ROOM_W, ROOM_H } from './drawRoom';
import { integerScale } from './scale';

// Draws the nook on a canvas, scaled by whole numbers only. Pip bobs every
// 700ms unless the user prefers reduced motion. Pass `view` from useMemo, so the
// drawing is not restarted on every render. The canvas is a picture for sighted
// users; the page shows the same state as text.
export default function NookCanvas({ view, animate = true, label, scale }) {
  const wrapRef = useRef(null);
  const canvasRef = useRef(null);
  const tick = useRef(0);
  const [measured, setMeasured] = useState(2);

  useLayoutEffect(() => {
    if (scale || !wrapRef.current) return undefined;
    const measure = () => setMeasured(integerScale(wrapRef.current.clientWidth));
    measure();
    if (typeof ResizeObserver === 'undefined') return undefined;
    const observer = new ResizeObserver(measure);
    observer.observe(wrapRef.current);
    return () => observer.disconnect();
  }, [scale]);

  useEffect(() => {
    const canvas = canvasRef.current;
    const ctx = canvas && canvas.getContext && canvas.getContext('2d');
    if (!ctx) return undefined;
    const paint = () => drawRoom(ctx, view, tick.current);
    paint();
    const reduced = typeof window !== 'undefined' && window.matchMedia && window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    if (!animate || reduced) return undefined;
    const timer = setInterval(() => {
      tick.current += 1;
      paint();
    }, 700);
    return () => clearInterval(timer);
  }, [view, animate]);

  const used = scale || measured;
  return (
    <div ref={wrapRef} style={{ width: '100%' }}>
      <canvas
        ref={canvasRef}
        width={ROOM_W}
        height={ROOM_H}
        role="img"
        aria-label={label}
        data-testid="nook-canvas"
        data-scale={used}
        style={{ width: ROOM_W * used, height: ROOM_H * used, display: 'block', imageRendering: 'pixelated', borderRadius: 6 }}
      />
    </div>
  );
}
```

```jsx
import React, { useEffect, useMemo, useRef } from 'react';
import { drawSprite } from './drawRoom';
import { pipSprite, SPRITE_WIDTH, CENTER } from './sprites';

const BOB_MS = 700;
const PREVIEW_MS = 5000;

// Pip on a flat cream panel. Used where Pip hosts a lesson and in the nook offer.
// With `animate` he bobs for five seconds and then holds still. Nothing moves for
// people who prefer reduced motion.
export default function PipPanel({ form = 'seed', mood = 'calm', animate = false, label = 'Pip', scale = 4 }) {
  const canvasRef = useRef(null);
  const rows = useMemo(() => pipSprite(form, mood), [form, mood]);
  const height = rows.length + 1;

  useEffect(() => {
    const canvas = canvasRef.current;
    const ctx = canvas && canvas.getContext && canvas.getContext('2d');
    if (!ctx) return undefined;
    const paint = (bob) => {
      ctx.clearRect(0, 0, SPRITE_WIDTH, height);
      drawSprite(ctx, rows, CENTER, height - 1 - bob);
    };
    paint(0);
    const reduced = typeof window !== 'undefined' && window.matchMedia && window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    if (!animate || reduced) return undefined;
    let bob = 0;
    const timer = setInterval(() => {
      bob = bob ? 0 : 1;
      paint(bob);
    }, BOB_MS);
    const stop = setTimeout(() => {
      clearInterval(timer);
      paint(0);
    }, PREVIEW_MS);
    return () => {
      clearInterval(timer);
      clearTimeout(stop);
    };
  }, [rows, height, animate]);

  return (
    <div className="inline-flex rounded-[10px] bg-[#F3EAD9] p-3" data-testid="pip-panel">
      <canvas
        ref={canvasRef}
        width={SPRITE_WIDTH}
        height={height}
        role="img"
        aria-label={label}
        style={{ width: SPRITE_WIDTH * scale, height: height * scale, imageRendering: 'pixelated', display: 'block' }}
      />
    </div>
  );
}
```

```jsx
import React, { useState } from 'react';
import { useNavigate } from 'react-router-dom';
import { speciesAPI } from '../lib/api';
import { READINESS_STEP_LABELS, READINESS_STATE_LABELS } from './nookCopy';

// For people with no plant yet. They pick a species and tick off three steps. The
// plant has only seed, sprouting, and ready states, and it never has a need.
export default function ReadinessPanel({ readiness, busy, onStart, onStep }) {
  const navigate = useNavigate();
  const [changing, setChanging] = useState(false);
  const [query, setQuery] = useState('');
  const [results, setResults] = useState(null);
  const [searching, setSearching] = useState(false);
  const [error, setError] = useState('');

  const search = async (event) => {
    event.preventDefault();
    if (query.trim().length < 2) {
      setError('Type at least two letters.');
      return;
    }
    setError('');
    setSearching(true);
    try {
      const res = await speciesAPI.search(query.trim());
      setResults(res.data || []);
    } catch (_e) {
      setError('Could not search plants. Try again.');
    } finally {
      setSearching(false);
    }
  };

  const pick = (species) => {
    setChanging(false);
    setResults(null);
    setQuery('');
    onStart(species.id);
  };

  if (!readiness || changing) {
    return (
      <section className="rounded-[14px] border-[0.5px] border-[#D3C9B8] bg-[#EDE5D8] p-4" data-testid="readiness-search">
        <h2 className="font-plant text-[#1C2E10] text-lg mb-1">Getting ready for a plant?</h2>
        <p className="text-sm text-[#1A1A17] mb-3">Pick the plant you have in mind. You&apos;ll get ready for it in three small steps.</p>
        <form onSubmit={search} className="flex gap-2">
          <label className="flex-1 text-xs font-ui text-[#2B2B26]">
            Plant name
            <input
              value={query}
              onChange={(event) => setQuery(event.target.value)}
              placeholder="Snake plant"
              className="mt-1 w-full rounded-[8px] border-[0.5px] border-[#D3C9B8] bg-[#F5F0E8] px-3 py-2 text-sm"
              data-testid="readiness-query"
            />
          </label>
          <button
            type="submit"
            aria-busy={searching}
            className="self-end rounded-[2px] font-plant uppercase tracking-[0.08em] text-xs px-4 py-3 border-[0.5px] bg-[#1C2E10] text-[#F5F0E8] border-[#1C2E10]"
            data-testid="readiness-search-button"
          >
            Search
          </button>
        </form>
        {error && (
          <p role="alert" className="mt-2 text-xs font-ui text-red-700" data-testid="readiness-error">
            {error}
          </p>
        )}
        {results && results.length === 0 && <p className="mt-2 text-xs font-ui text-[#2B2B26]">No plants found. Try another name.</p>}
        {results && results.length > 0 && (
          <ul className="mt-3 space-y-2">
            {results.slice(0, 8).map((species) => (
              <li key={species.id}>
                <button
                  type="button"
                  onClick={() => pick(species)}
                  className="w-full text-left rounded-[8px] border-[0.5px] border-[#D3C9B8] bg-[#FDFAF6] px-3 py-2 text-sm hover:border-[#2D5016]"
                  data-testid={`readiness-result-${species.id}`}
                >
                  {species.common_name}
                </button>
              </li>
            ))}
          </ul>
        )}
        {readiness && (
          <button type="button" onClick={() => setChanging(false)} className="mt-3 text-xs font-ui underline text-[#2D5016]">
            Keep {readiness.species_name}
          </button>
        )}
      </section>
    );
  }

  return (
    <section className="rounded-[14px] border-[0.5px] border-[#D3C9B8] bg-[#EDE5D8] p-4" data-testid="readiness-panel">
      <h2 className="font-plant text-[#1C2E10] text-lg">Getting ready for a {readiness.species_name}</h2>
      <p className="text-sm text-[#1A1A17] mb-3" data-testid="readiness-state">
        {READINESS_STATE_LABELS[readiness.state]}. This is a practice plant, so it never needs anything.
      </p>
      <ul className="space-y-2">
        {readiness.steps.map((step) => (
          <li key={step.id} className="flex items-center justify-between gap-3 rounded-[8px] bg-[#FDFAF6] px-3 py-2">
            <span className="text-sm font-ui text-[#1A1A17]">{READINESS_STEP_LABELS[step.id]}</span>
            {step.done ? (
              <span className="text-xs font-ui text-[#3B6D11]" data-testid={`readiness-done-${step.id}`}>
                Done
              </span>
            ) : (
              <button
                type="button"
                onClick={() => onStep(step.id)}
                aria-busy={busy}
                className="rounded-[2px] font-plant uppercase tracking-[0.08em] text-[10px] px-3 py-2 border-[0.5px] border-[#1C2E10] text-[#1C2E10]"
                data-testid={`readiness-step-${step.id}`}
              >
                Mark done
              </button>
            )}
          </li>
        ))}
      </ul>

      {readiness.state === 'ready' && (
        <div className="mt-3" data-testid="readiness-ready">
          <p className="text-sm text-[#1A1A17]">
            A {readiness.species_name} usually likes water about every {readiness.watering_days} days.
          </p>
          <p className="font-plant text-[#1C2E10] text-base mb-2">Ready to meet a real one?</p>
          <button
            type="button"
            onClick={() => navigate('/add-plant')}
            className="rounded-[2px] font-plant uppercase tracking-[0.08em] text-xs px-4 py-3 border-[0.5px] bg-[#1C2E10] text-[#F5F0E8] border-[#1C2E10]"
            data-testid="readiness-add-plant"
          >
            Add a plant
          </button>
        </div>
      )}

      <button type="button" onClick={() => setChanging(true)} className="mt-3 text-xs font-ui underline text-[#2D5016]" data-testid="readiness-change">
        Pick a different plant
      </button>
    </section>
  );
}
```
